## 🗂️ Repository Structure
The code is organized logically by topic and complexity to demonstrate consistent progression:
* `01-fundamentals/` – Variables, data types, loops, and conditional logic.
* `02-functions-and-scope/` – Arrow functions, closures, and scope chains.
* `03-dom-manipulation/` – Interactive UI elements, event listeners, and dynamic styling.
* `04-asynchronous-js/` – Promises, API fetching (`fetch`), and Async/Await.
* `05-mini-projects/` – Capstone projects built by applying combined knowledge.
